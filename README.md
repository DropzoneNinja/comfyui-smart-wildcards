# Smart Wildcards

A ComfyUI custom node providing a table-based UI for combining wildcard text files (under `/basedir/wildcards`) into a single prompt string.

**Status: under active development, not yet installable/usable.** Only backend discovery logic (directory scanning, entry parsing, path validation, file creation) exists so far.

- [PROJECT.md](PROJECT.md) — the product/behavior specification
- [DESIGN.md](DESIGN.md) — the technical design
- [TASKS.md](TASKS.md) — implementation progress tracker

Full installation and usage instructions will be written in Milestone 8 once the node is functional end-to-end.
